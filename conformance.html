    How to read this page

    Measurement scope

    The source snapshot is identified by the SysML-v2-Pilot-Implementation and SysML-v2-Release tags shown above. Manifest entries provide the main source file and dependency list.

    For interchange, each manifest entry is parsed and compared with the corresponding Pilot JSON under the gate-specific normalization rules. For text fidelity, the source is parsed and unparsed and the material-token streams are compared.

    For visualization, run.py all reads the oracle index for each view kind. generate-graphics.py loads the Pilot standard library, parses each indexed source with Pilot GenViz, and writes Pilot SVG plus PlantUML. It passes the same indexed source set to smlml render <source> --kind <view-kind> --force --format dot; Graphviz converts the resulting DOT to SVG. The conformance runner reduces the Pilot PlantUML and Small ML DOT to a common structural form and compares nodes, compartments, ownership or membership, edges, labels, styles, shapes, and order. The %view population instead runs one smlml render <source> --view <qualified-name> --force --format dot invocation per indexed ViewUsage and is judged on structural axes; rendered and React measurements are part of the other %viz populations.

    Validation and specification rows report the status recorded in the Pilot coverage and specification coverage artifacts. The complete deviation register is rendered in the detailed results.

    1. Read the pinned source tags and the committed conformance manifests.
    2. Use the manifest source list and the view oracle index as the input populations; standard-library imports are resolved by the Pilot and Small ML toolchains.
    3. Run the relevant Pilot and Small ML parse, unparse, validation, or rendering path; the visualization reproduction command is python3 assets/conformance/visualization/scripts/run.py all.
    4. Compare the resulting JSON, material-token, or graphic structure and record the reported delta.

    The report is assembled during the web build from committed conformance artifacts. Detailed data and graphics are loaded only after the results button is selected.
